# Machine Learning in Finance

Course materials for *Machine Learning in Finance* (undergraduate, West Virginia University).

* **notebooks/** — the weekly labs. Open a notebook and click the **Open in Colab** badge at its top. Run the
  **▶ RUN ME FIRST** cell, then work through the cells in order. Save your own copy with *File → Save a copy in Drive*.
* **mlfin.py** — the course helper module the notebooks use. You never need to edit it; open it (or ask an AI
  assistant to explain it) if you are curious how something works.
* **data/** — the course dataset. `data/DATA_README.md` explains every file, where it came from, and its known gaps.

No installation is needed: everything runs in Google Colab in your browser.
